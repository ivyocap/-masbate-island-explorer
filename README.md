# Masbate Island Explorer

An original, responsive travel-themed website made for Activity 01: All or Nothing.

## Files
- `index.html` — Home page
- `about.html` — About page
- `gallery.html` — Photo gallery
- `css/style.css` — All website styling
- `images/` — Folder reserved for downloaded/local images

## Requirements followed
- HTML5 and CSS3 only
- No JavaScript
- Three linked HTML pages
- Responsive layout for phones and computers
- CSS hover and focus effects
- Ready for GitHub Pages

## Preview locally
Open `index.html` in a browser. Keep the folder structure unchanged.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `masbate-island-explorer`.
2. Upload all files and folders from this project. Make sure `index.html` is in the repository's root folder.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish. Your website address will look like `https://YOUR-USERNAME.github.io/masbate-island-explorer/`.

## Notes
The gallery and background photographs load from Unsplash, so an internet connection is needed to display them. Replace them with your own properly credited images if desired. The fourth gallery image is optional and can be replaced if it does not load on your device.
